# 产品笔记

这一层收**具体产品**的使用笔记，一个产品一个目录，记录组件构成、配置项位置与版本行为差异。产品漏洞的利用手法归红蓝攻防分区，这里只留「它是怎么用的」。

## 收录范围

| 子目录 | 内容 | 状态 |
|---|---|---|
| [`Microsoft-Exchange`](./Microsoft-Exchange/index.md) | Exchange 在 IIS 中的虚拟目录构成，Autodiscover、ECP、EWS、MAPI、OAB、OWA、EAS、PowerShell 八项各自对应的服务与访问方式 | ECP、OWA 两节目前只有标题，正文待补写 |

当前只有 Exchange 一项。产品数量少时保持单层目录，等同一厂商积累出多个产品再考虑加一层厂商目录。

## 收录约定

产品名、组件名与配置路径保留原文，同一产品的多个主题合并在同一目录内，不按功能拆到其他分区。
