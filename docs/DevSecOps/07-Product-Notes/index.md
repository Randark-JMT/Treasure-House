# 产品笔记

这一层收具体产品的使用笔记，一个产品一个目录，记的是组件构成、配置项在哪、不同版本之间的行为差异。产品漏洞的利用手法不归这里，那在红蓝攻防分区；这一层只回答「它是怎么用的」。

以 Exchange 为例，本层记它在 IIS 里的虚拟目录构成，以及八个入口各自对应什么服务、怎么访问。拿这些入口做文章的手法不写在这里。

## 收录范围

| 子目录 | 内容 | 状态 |
|---|---|---|
| [`Microsoft-Exchange`](./Microsoft-Exchange/index.md) | Exchange 在 IIS 中的虚拟目录构成，Autodiscover、ECP、EWS、MAPI、OAB、OWA、EAS、PowerShell 八项各自对应的服务与访问方式 | ECP、OWA 两节目前只有标题，正文待补写 |

当前只有 Exchange 一项，目录就保持单层。等同一厂商积累出多个产品再考虑加一层厂商目录，现在加是空架子。

## 收录约定

产品名、组件名与配置路径保留原文，不翻译也不换成自己的叫法——查资料、搜报错的时候，原文才是能对上号的那个字符串。同一产品的多个主题合并在同一目录内，不按功能拆到其他分区。
