# 实验环境

这一层收用来搭实验的环境软件本身：跑在哪、怎么装、装完怎么起拓扑。环境里跑的攻击手法不写在这里，按分区分工归对应的知识域。

## 收录范围

| 子目录 | 内容 |
|---|---|
| [`EVE-ng`](./EVE-ng/index.md) | 网络仿真平台 EVE-ng，用于在一台宿主机上搭多层网络拓扑 |

目前只有 EVE-ng 一项。目录下已有一篇 [`Installation`](./EVE-ng/Installation/index.md)：下载官方社区版（Community Edition）Live ISO，新建虚拟机挂载安装，按 Ubuntu Server 流程走完。页面附了安装界面截图，也提醒安装时不要启用简易安装模式。

这一层与 `04-Writeups` 的分工是：这里写环境怎么起，那边写起来之后打通了什么。EVE-ng 这类要单独装的环境软件归这边；随某个靶场一起交付的 docker-compose 编排跟着靶场走，在 `04-Writeups` 下。

## 收录约定

环境页面写可复现的最小步骤。镜像下载地址、版本号与关键配置保留原文，宿主机与版本差异在页内显式标注——别人复现失败，多半就卡在这两处。同一环境的不同版本各写一篇，不覆盖旧步骤：旧版本的环境往往还在用，覆盖掉就没人能照着复现了。
