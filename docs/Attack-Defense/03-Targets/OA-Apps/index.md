# OA Apps - 办公应用

本分类收录办公协同与应用服务类目标的攻击页面。目录名取自办公自动化（Office Automation，OA），收录的五个目标却不完全算 OA。

## 收录范围

这五个凑得比别的分类杂。Confluence 是 wiki 协同平台，E-cology 是企业 OA 套件，对得起目录名；Arcgis-rest-service 是 GIS 平台对外露出的 REST 接口，跟办公的关系只剩同在一个业务网里。BsPHP 和 Snor 名字不常见，各自的页面里能查到的信息也最少。
