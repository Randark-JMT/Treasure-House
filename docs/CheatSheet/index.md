# CheatSheet

> ***少打字，多办事***

这一区放**跨知识域的速查表**：实战里会直接复制粘贴的命令组合、参数顺序和容易记错的细节。

与其他分区的区别是刻意划定的——它属于「形态类」分区，判断标准不是「这条知识属于哪个域」，而是「你在什么场景下需要 5 秒内找到它」。所以一页可以横跨 Windows 后渗透与 Linux 提权，但不收方法论、不收背景解释，那些内容归各自的知识域分区，这里只留一句结论加一条链接。

## 现有条目

- [Windows 后渗透](./Windows-Post-Exploitation.md) — 文件挖掘与回传、凭据提取、横向移动的速查命令

## 收录约定

- 一页一场景，标题用动宾短语（「文件挖掘回传」而不是「文件挖掘」）。
- 命令必须可直接执行，路径、正则与引号写法按原样保留；破坏性操作前置条件写在命令上方。
- 只收自己踩过或公开可复现的写法，未验证的条目显式标 `待验证`。
